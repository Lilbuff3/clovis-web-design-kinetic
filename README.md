## Overview

A modern high-motion creative studio prototype designed for **Clovis Web Design**. Blends Swiss-modern layout discipline with fluid spring physics, interactive canvas geometry, and rapid client case study exploration.

### Featured Client Case Studies
1. **Kidney Specialist Inc** ([kidneyspecialistinc.com](https://kidneyspecialistinc.com)) — Nephrology medical practice for Dr. Sheikh Mohammad Masood & Dr. Mohammed Siddiqui in Madera & Fresno, CA. Built to CMS & WCAG 2.1 AA accessibility guidelines with a zero-HIPAA liability direct-call & fax architecture.
2. **Big Bros Dumpster Rentals** ([bigbrosdumpsterrental.com](https://bigbrosdumpsterrental.com)) — Premier family-owned roll-off dumpster hauler for Jessica & William Maldonado Ramirez in Clovis & Fresno, CA. Features flat-rate pricing, bilingual trade copy, and Geo-SEO radius architecture.
3. **Clovis Web Design Studio** ([cloviswebdesign.com](https://cloviswebdesign.com)) — Central Valley digital flagships with sub-second speeds, 100% asset ownership, and direct craftsman delivery.

## Tech Stack
- **Framework**: React 19 + TypeScript + Vite 7
- **Styling**: Tailwind CSS v4
- **Animation**: Motion (Framer Motion v13) spring physics
- **Icons**: Lucide React
- **Typography**: `Manrope`, `Instrument Serif`, `DM Mono`
- **Build**: Single-file bundle capable via `vite-plugin-singlefile`

---

## Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build production bundle
npm run build

# Preview build
npm run preview
```
